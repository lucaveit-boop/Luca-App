LUCA 1.0 Upgrade

WICHTIG: Vor dem Hochladen in der installierten LUCA-App unter Mehr ein JSON-Backup exportieren.

In GitHub Luca-App die sechs Dateien index.html, manifest.webmanifest, sw.js und drei Icons ersetzen bzw. hochladen. README-UPDATE.txt muss nicht hochgeladen werden.

Diese Version nutzt weiterhin localStorage-Schlüssel luca_v04_data und Datenversion 4. Sie übernimmt dadurch Einträge der V0.4 bei identischem Ursprung und identischem Browserspeicher. Browser und installierte Web-App können getrennte Speicher haben.

Neue Funktionen: Budget, 7-Tage-Ausgabenbalken, Fokusminuten, Tagesübersicht, Mini-Aufgaben, geführte Trainings, Online-Lebensmittelsuche über Open Food Facts. Kein Kamera-Barcode-Scanner und keine automatische Foto-Kalorienanalyse.

Für GitHub Pages: Settings > Pages > main / (root). Bei altem Cache Safari/Web-App neu öffnen.
